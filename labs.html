CYBER LABS

Test your skills in our custom-built virtual environments. From basic network reconnaissance to advanced exploitation.

HOW TO START

To access the labs, you need to run the Docker containers on your local machine. Ensure you have Docker and Docker Compose installed.

  1. Clone the repository or download the challenges folder.
  2. Navigate to the challenges directory.
  3. Run the startup command.
  4. Connect to the target ports as specified in the challenge details.
# Clone the repo (if you haven't already) git clone cd challenges # Start all challenges docker-compose up -d --build # Check running services docker ps

ACTIVE CHALLENGES

Level 1: Low

Network Basics

A poorly configured server exposing unnecessary services. Your goal is to gain access and escalate privileges.

Ports: 2121 (FTP), 2221 (SSH)
Flags: 2 (User, Root)
Skills: Reconnaissance, Default Credentials, Weak Permissions, Basic Privilege Escalation.
Level 2: Mid

Web Exploitation

A corporate portal with a custom login system. Rumor has it the developers skipped security reviews.

Port: 8082 (HTTP)
Flags: 2 (DB, Root)
Skills: SQL Injection, Code Review, SUID Binary Exploitation.
Level 3: High

Advanced Ops

A critical network diagnostic tool running with high privileges. It seems secure, but inputs are tricky.

Port: 8083 (HTTP)
Flags: 2 (User, Root)
Skills: Command Injection, Wildcard Injection, Misconfigured Capabilities/Sudo.
